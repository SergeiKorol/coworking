# Дизайн: схема занятости — полный SVG и подсветка номеров

**Дата:** 2026-11-20  
**Статус:** отменена — заменена [2026-11-21-availability-floor-png-svg-overlay-design.md](./2026-11-21-availability-floor-png-svg-overlay-design.md)  
**Родительский scope:** [2026-11-13-availability-ui-v2-design.md](./2026-11-13-availability-ui-v2-design.md)

## Цель

Заменить на странице `/availability` связку **PNG + CSS-текстовые оверлеи** на **единый inline-SVG** (полная векторная схема). Статус мест показывается **только цветом** на плане; текст «свободен / занят» на схеме **не используется**. Блок **карточек** под схемой **сохраняется** на всех брейкпоинтах.

## Вне scope

- Изменение логики `build_day_unit_statuses`, каталога, админки.
- Кликабельная интерактивная карта (бронь с сайта).
- Отдельная мобильная вёрстка страницы (кроме адаптивного `viewBox` SVG).
- Гибрид PNG внутри SVG (зафиксирован **чистый вектор**).

## Принятые решения (сессия брейншторма)

| Тема | Решение |
|------|---------|
| Брейкпоинты | Одинаковое поведение везде (нет текстовых бейджей на плане) |
| Носитель схемы | **Полный векторный SVG** (контур плана, мебель, подписи зон — пути/тексты) |
| Столы 1–8 | Кружок: **белый** = свободно, **фуксия** = занято; цифра: **тёмная** / **белая** соответственно |
| Переговорка `meeting-room` | Заливка **поверхности стола** (не кружок с буквой): белый / фуксия |
| Карточки под схемой | **Оставить** как в v2 (текст + цвет карточки) |
| Легенда цветов на странице | Не добавлять |

## Поведение UI

### Структура страницы

Шапка, заголовок даты, полоса 7 дней — **без изменений**.

Блок схемы:

```text
<div class="floor-plan-wrap">
  {% include "public/floor_plan.svg" %}  <!-- или inline partial -->
</div>
```

- Корневой `<svg>`: `width="100%"`, `height="auto"`, `preserveAspectRatio="xMidYMid meet"`, фиксированный `viewBox` (например `0 0 1200 1400` — уточняется при трассировке макета).
- `role="img"`, дочерний `<title>` с датой: «Схема коворкинга, занятость на ДД.ММ.ГГГГ».
- Декоративные слои (стены, подписи «ПЕРЕГОВОРКА», «ОСНОВНОЙ ЗАЛ», логотип WORK на схеме) **без** привязки к статусу — статичные `fill`/`stroke` как в макете.
- Девять **управляемых** групп (`desk-1` … `desk-8`, `meeting-room`), по одной на unit из каталога.

### Подсветка столов (hot_desk)

Для каждого `desk-N`:

- Группа `<g id="desk-N" class="floor-unit floor-unit--free|floor-unit--busy" data-unit-id="desk-N" aria-label="…">`.
- Внутри: `<circle>` (номерной бейдж) + `<text>` с цифрой `N` (центрирование через `text-anchor="middle"` / `dominant-baseline="central"`).
- Координаты круга совпадают с визуальными кружками на эталонном макете (не дублировать цифры из растра — **единственный** источник цифр на столах — SVG).

CSS (или атрибуты через Jinja — предпочтение **CSS по классу группы**):

| Состояние | Заливка круга | Цвет цифры | Обводка круга |
|-----------|----------------|------------|----------------|
| `floor-unit--free` | `#ffffff` | `#1a1a1a` | `stroke: rgba(0,0,0,0.25)` (чтобы белый читался на светлой столешнице) |
| `floor-unit--busy` | `#d946ef` | `#ffffff` | `stroke: rgba(0,0,0,0.15)` (опционально) |

Допускается смена hex фуксии на `#ff00ff`, если визуально ближе к брифу; в реализации зафиксировать **одну** константу в CSS.

### Подсветка переговорки

- Группа `<g id="meeting-room" class="floor-unit floor-unit--free|floor-unit--busy" …>`.
- Элемент стола: один `path` или `rect` с `rx` (форма как на макете).
- `floor-unit--free` → `fill: #ffffff` (или `fill` как у макета, если стол уже белый — отличие занятости только в `floor-unit--busy`).
- `floor-unit--busy` → `fill: #d946ef` (тот же оттенок, что у занятых столов).

### Удаляемое

- Разметка `div.floor-overlay-marker` и стили `.floor-overlay-marker*` в `availability-v2.css`.
- Передача `overlay_markers` в шаблон (после миграции координаты из `floor_overlay.py` либо не нужны, либо живут только в SVG).
- Зависимость публички от растрового `floor-plan.png` / `floor_plan.png` для **отображения** схемы (файл PNG можно оставить в репо как референс для трассировки, но **не** отдавать в `availability.html`).

### Карточки

Без изменений: сетка столов + карточка переговорки, классы `unit-card--free` / `unit-card--busy`. Текстовый статус для пользователей и screen reader — **здесь**.

### Доступность

- У каждой группы `floor-unit`: `aria-label` из `display_name` и короткого статуса («Стол 3, свободен» / «Переговорка, занята») — значения с сервера, как в карточках.
- SVG не дублирует длинные описания; карточки остаются основным текстовым представлением.

## Архитектура и код

### Шаблоны

| Файл | Назначение |
|------|------------|
| `app/templates/public/availability.html` | Подключает partial SVG вместо `img` + цикл оверлеев |
| `app/templates/public/floor_plan.svg` | Partial: корневой SVG + статичная графика + цикл Jinja по `unit_statuses` только для **классов** на `<g>` ИЛИ весь SVG статичен, а классы выставляются через `status_by_id[unit_id].occupied` на известные `id` |

Рекомендуемый паттерн: **статичная разметка** всех `<g id="desk-1">` … в partial; внутри каждой группы в начале:

```jinja
class="floor-unit {% if status_by_id['desk-1'].occupied %}floor-unit--busy{% else %}floor-unit--free{% endif %}"
```

(без дублирования геометрии в Python).

### Python

- `app/catalog/floor_overlay.py`: **удалить** или переименовать в устаревший; публичный blueprint **не** импортирует маркеры CSS.
- `app/blueprints/public.py`: убрать `overlay_markers=FLOOR_OVERLAY_MARKERS` из `render_template`.
- Логика availability без изменений: `unit_statuses`, `status_by_id`.

### Статика

| Файл | Назначение |
|------|------------|
| `app/static/css/availability-v2.css` | Стили `.floor-unit--free/busy`, `.floor-plan-svg`; удалить overlay-маркеры |
| `app/static/images/floor_plan.png` (опц.) | Референс для векторизации, не в runtime HTML |

### Создание SVG-ассета

1. Импорт текущего макета в Figma / Inkscape.
2. Трассировка: комнаты, столы (без отдельных растровых цифр — цифры только в управляемых `<text>`).
3. Единый `viewBox`; экспорт **как фрагмент** в `floor_plan.svg` partial (ручная чистка id, группировка под `desk-N` / `meeting-room`).
4. Визуальная сверка с PNG-referens в браузере на desktop и ~360px ширины.

## Тестирование

| Проверка | Ожидание |
|----------|----------|
| `GET /availability` | 200; в HTML есть `<svg` с классом `floor-plan-svg` (или аналог) |
| Нет legacy overlay | В теле **нет** `floor-overlay-marker` |
| Занятость | При фикстуре confirmed на `desk-2`: `id="desk-2"` (или `data-unit-id`) с классом `floor-unit--busy` |
| Свободен | Unit без брони: `floor-unit--free` |
| Переговорка | `meeting-room` + busy/free по брони |
| Карточки | По-прежнему присутствуют `unit-card` |
| Регрессия | Существующие тесты availability/catalog/public routes — зелёные после обновления ассертов при необходимости |

Не требуется pixel-perfect автотест SVG; достаточно проверки классов и отсутствия старой разметки.

## Риски и смягчение

| Риск | Смягчение |
|------|-----------|
| Долгая трассировка макета | Итерация: сначала геометрия залов + 9 status-групп; декор (логотип на плане) — вторым коммитом |
| Белый «свободен» сливается с фоном | Обводка круга; для стола переговорки контраст «белый vs фуксия» на тёмном полу зала |
| Расхождение 8 столов в коде vs старый текст spec v2 «7 столов» | Истина — **каталог** (`desk-1`…`desk-8`); SVG обязан включать **8** групп |

## Связь с v2

Документ **заменяет** для публичной схемы строки v2 «PNG + CSS overlay» и файл `floor-plan.png` в runtime. Карточки, шапка, redirect `/` — без изменений.
