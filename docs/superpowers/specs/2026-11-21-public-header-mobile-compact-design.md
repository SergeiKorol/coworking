# Дизайн: компактная шапка на мобилке (без логотипа)

**Дата:** 2026-11-21  
**Статус:** утверждён пользователем  
**Scope:** публичные страницы (`base_public.html`)

## Цель

На экранах **≤768px** не показывать логотип WORK в шапке, чтобы уменьшить высоту. Оставить по центру: **Коворкинг**, адрес, телефон. На **десктопе** — без изменений (3 колонки с логотипом).

## Решение

- CSS в `availability-v2.css` внутри существующего `@media (max-width: 768px)`:
  - `.site-header__logo { display: none; }`
  - Необязательно: уменьшить вертикальный `padding` у `.site-header`.
- HTML не менять (логотип остаётся для `md+`).
- Админка не затрагивается.

## Тесты

- В `availability-v2.css` присутствует скрытие `.site-header__logo` в mobile media query.
